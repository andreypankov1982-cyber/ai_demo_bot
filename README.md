# Beauty Salon Telegram Bot

Профессиональный Telegram-бот для салона красоты: принимает заявки 24/7, отвечает на вопросы клиентов, помогает владельцу отслеживать лиды и демонстрирует продуктовый сценарий "цифрового администратора".

## Продуктовая ценность

- **Больше заявок**: клиент записывается в пару кликов прямо в Telegram.
- **Меньше ручной рутины**: бот собирает имя, телефон, услугу, мастера и желаемую дату.
- **Контроль для владельца**: статистика, просмотр лидов, экспорт базы.
- **Быстрая коммуникация**: встроенные ответы на вопросы через GPT.
- **Демо-формат для продаж**: отдельный сценарий клиента и владельца.

## Основные возможности

### Для клиента
- Роль "Я клиент" с отдельным меню.
- Онлайн-запись на услугу с пошаговой формой (FSM).
- Просмотр своих записей.
- Блок "Вопрос" с быстрыми ответами.

### Для владельца
- Роль "Я владелец салона" с проверкой доступа.
- Просмотр статистики и новых заявок.
- Экспорт лидов в CSV.
- Блок "Вопрос" о возможностях продукта.

## Технологии

- Python 3.11
- aiogram 3
- aiohttp
- aiosqlite (SQLite)
- pydantic + pydantic-settings
- tenacity
- cachetools

## Структура проекта

- `bot.py` - основной файл бота (handlers, FSM, GPT, DB-операции)
- `config.py` - загрузка и валидация конфигурации из окружения
- `requirements.txt` - зависимости Python
- `.env.example` - пример переменных окружения
- `docker-compose.yml` - запуск контейнера
- `Dockerfile` - сборка образа

## Конфигурация

Создайте `.env` на основе `.env.example`:

```env
TG_BOT_TOKEN=your_bot_token
OPENAI_API_KEY=sk-...
OWNER_CONTACT=123456789
GPT_MODEL=gpt-4o-mini
GPT_TEMPERATURE=0.3
GPT_MAX_TOKENS=250
GPT_TIMEOUT=40
```

## Локальный запуск

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

### Логи

Логи пишутся в файл `bot.log`.

## Docker запуск

### Сборка образа

```powershell
docker build -t beauty-salon-bot .
```

### Запуск контейнера

```powershell
docker-compose up -d
```

### Просмотр логов

```powershell
docker-compose logs -f
```

### Остановка

```powershell
docker-compose down
```

## Команды в Telegram

### Общие
- `/start` - стартовое меню
- `/help` - справка
- `/clear` - очистка истории диалога

### Для владельца
- `/stats` - статистика
- `/leads` - последние заявки
- `/export` - экспорт лидов в CSV

## Демо-сценарий для презентации

1. Пользователь выбирает роль клиента.
2. Проходит форму записи (услуга -> мастер -> дата -> имя -> телефон).
3. Владелец получает уведомление о новой записи.
4. Владелец открывает статистику и список лидов.
5. Показывается блок вопросов (клиент/владелец) с живыми ответами.

## Безопасность

- Секреты (`TG_BOT_TOKEN`, `OPENAI_API_KEY`) хранятся в `.env`.
- `.env` и `bot.db` не копируются в Docker-образ.
- Доступ к owner-функциям ограничен `OWNER_CONTACT`.

## Ограничения демо-версии

- Используется SQLite (подходит для демо и небольших нагрузок).
- Нет веб-панели администратора.
- Нет интеграции с внешней CRM.
